# Calculadora Dutra

Uma calculadora simples feita com HTML, CSS e JavaScript puro, com visual inspirado no iPhone.

## Como usar

Basta abrir o arquivo `index.html` no navegador.

## Estrutura

- `index.html` — estrutura da página e dos botões
- `style.css` — estilo visual (tela, botões, layout estilo iPhone)
- `script.js` — lógica da calculadora

## Funcionalidades

- Operações básicas: soma, subtração, multiplicação e divisão
- Porcentagem
- Limpar (C) e apagar último caractere
- Relógio no topo da tela, como na interface do iPhone
